## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Requested by the user on 2026-10-25: STSX gets its own section on the site, between Docs and UI in the menu, with its own llms.txt, so that agents and humans can adopt `.stsx` without the Lumiose framework. The section is the docs of STSX itself.

It follows the /ui section (decision-64, TASK-387):
- **Source.** The pages are packages/stsx/docs (written in TASK-583), which ship in @lumiose/stsx.
- **llms files.** A generator in @lumiose/cli's docs module (as for @lumiose/ui) writes packages/stsx/docs/llms.txt and llms-full.txt, in the reading order of the docs README's Pages list.
- **Site.** apps/web renders /stsx/ and /stsx/<page>/ in the docs shell, serves /stsx/llms.txt and /stsx/llms-full.txt with site links, lists them in the site's llms.txt, adds the pages to search, and adds the menu entry.
<!-- SECTION:DESCRIPTION:END -->

## Implementation Notes

<!-- SECTION:NOTES:BEGIN -->
2026-10-25 (Lux): planned and taken in the same standalone M14 run, at the user's request.

2026-10-25 (Lux):

**Generator.** `generateStsxLlms` in packages/cli/src/docs/generate.ts writes the index (README) and then the pages, in the order of the README's own links. packages/stsx has `docs:gen` and `docs:check` (scripts/gen-llms.ts, as packages/ui does), and src/docs.test.ts keeps the generated files current (so `pnpm test` catches stale files).

**Site** (apps/web):
- **Content layer.** content/docs.ts gains an stsx collection (topics below `stsx/`, reading order from STSX's llms.txt, navigation section "STSX"), `stsxPages`, `findStsxPage`, previous and next within the section, `/stsx` URLs, and rewriting of `https://itsjavi.com/lumiose/stsx/` links.
- **Routes.** routes/stsx/layout.stsx (DocsShell with a More section: STSX llms.txt, Styles in Lumiose, Lumiose docs), routes/stsx/[[...path]]/page.stsx (DocArticle, staticPaths), and routes/stsx/llms.txt and llms-full.txt (content/llms.ts `stsxLlmsText` / `stsxLlmsFullText`, links pointing at the site).
- **Search.** search.json includes the STSX pages.
- **Menu.** lib/site.ts has STSX between Docs and UI in the header, plus footer links ("STSX outside Lumiose", "STSX llms.txt").

**Lumiose docs.** The README gains an STSX section (before UI) linking /stsx/llms.txt, so the site's llms.txt lists it. lumiose docs:gen and docs:check pass.
