## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
No page had og:image, og:url, a canonical link or a Twitter card. The audit of the built site (172 indexable pages) found 64 descriptions over 160 characters (doc summaries used as is), short descriptions on several main pages (showcase, benchmarks) and short or keyword-poor titles on the docs and UI landing pages. ## Implementation Notes

<!-- SECTION:NOTES:BEGIN -->
Solo takeover by Lux (standalone).
- OG images: apps/web/scripts/og-images.ts (pnpm --filter @lumiose/web og:images) renders three 1200x630 HTML cards in the home hero's night-stage style with Playwright into apps/web/public/og/{home,stsx,ui}.png (335-403 kB). Fonts load from Google Fonts at generation time only.
- Head: document.tsx holds the defaults (og:site_name, og:type, the home og:image with size and alt, twitter:card summary_large_image); Lumiose's head dedupe lets a page replace them. New PageMeta (title, description cut to 160 by metaDescription, og:title/description/url, canonical with the trailing slash GitHub Pages redirects to, optional image) replaces the hand-written Title/Meta on the home, docs/STSX/UI pages (DocArticle), showcase, benchmarks and playground. The 404 page and the redirect stubs keep no canonical.
- Titles and descriptions: home 'Lumiose web framework: feels like React, runs like vanilla JS' (og:title keeps the tagline); docs index 'Lumiose docs: guides, concepts and API reference'; UI index 'Lumiose UI: accessible components on native HTML'; showcase 'Showcase: apps made with Lumiose'; benchmarks 'Benchmarks: Lumiose vs Next.js, SvelteKit, Astro and more'; playground 'Lumiose playground: try .stsx components in the browser'. Hand-written descriptions for the docs, STSX and UI landing pages, showcase, benchmarks and js-framework-benchmark; diagnostics get 'Lumiose diagnostic LUMxxxx: <summary> What it means, an example, and how to fix it.'
- Audit of the built site (172 indexable pages): before, 64 descriptions over 160 characters and 28 under 70, no og:image, og:url, canonical or Twitter card; after, none over 160 (decoded), none under 70, no duplicate titles, one of each tag per page.
- Evidence: apps/web vitest (31, including the new src/lib/site.test.ts), lumiose check, the landing and UI e2e tests (title assertions updated), oxlint, oxfmt, the head tags of 10 pages read from the dev server, and the full pnpm build:site.
- Not done: internal links have no trailing slash, so GitHub Pages answers each with a 301 to the slash URL (trailingSlash: 'always' would fix it; a separate change).
