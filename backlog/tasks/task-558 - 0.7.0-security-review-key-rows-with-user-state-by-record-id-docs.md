Prism's 0.7.0 delta review (2026-10-24), Info: with decision-83 a kept keyed row keeps its DOM state when a different record arrives under the same key. A row keyed by index with an unbound checkbox in a delete-selected form would stay checked next to a different record after a filter or sort. Same as React and Vue; an app-code risk. Lux added a docs note to concepts/jsx.md (Lists and keys). Optional follow-up: a compiler hint for index-only keys on rows with form controls.
