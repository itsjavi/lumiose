## Description

Planned with the user on 2026-10-15, from a comparison with React Router's framework mode. Extension points Lumiose lacks: folder-scoped middleware with ctx.route, a client entry hook, router lifecycle hooks, per-instance form submissions, server and client instrumentation, and a dev handler for custom servers. Plus Coming from guides for React Router, Next.js, React and Solid. Every new API shape is approved by the user in the milestone's design task before it is implemented; route loaders, RPC server functions (decision-18) and routes defined in code (decision-42) stay out of scope.
