## Description

The accessible UI primitives package @lumiose/ui (decision-54): a Timeless-based direction with Base UI's API as inspiration and Zag.js considered later for widgets Timeless lacks. A spike decides whether to depend on, port or merge Timeless; the package keeps its own 0.x versions outside lockstep. Starts after M10.
