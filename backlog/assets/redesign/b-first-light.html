Getting started

Words on the left, the code they describe on the right.

Step 1

Create a project

Pick a template. The rendering mode can change later.

Terminal
pnpm create lumiose my-app --template ssr
cd my-app && pnpm install && pnpm dev
Step 2

Write a component

A component is a function. State is a signal.

Read it by calling it. Write it with set.

src/routes/page.stsx
import { signal } from "lumiose";

export default function Home() {
  const name = signal("world");
  return (
    <>
      <input value={name()} onInput={(e) => name.set(e.currentTarget.value)} />
      <h1>Hello, {name()}!</h1>
    </>
  );
}
Hello, world!
Step 3

Style it in the same file

One <style> block at the end. Selectors match only this file's markup.

src/routes/page.stsx
<style>
  h1 { letter-spacing: -0.02em; }   /* only this h1 */
</style>
Step 4

Check it

Types, templates and styles in one command.

Needs Node 24+, TypeScript 7, Vite 8.

Terminal
pnpm lumiose check
