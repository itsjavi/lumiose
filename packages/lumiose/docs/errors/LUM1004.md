# LUM1004: Unclosed `<style>` block

**Severity:** error · **Category:** file format (1xxx)

<!-- end of generated header -->

> A `<style>` block has no closing `</style>`.

**Reported by:** the scanner (compiler, `lumiose check`, language server).

## What it means

Block content runs up to the first `</style>`. Without one, the rest of the file would be CSS, so
the scanner stops and reports the block.

## Example

```stsx
export function Card() {
  return (
    <div class="card">
      <style>
        .card { padding: 1rem; }
    </div>
  );
}
```

## How to fix it

Close the block with `</style>` before the end of its parent element. A self-closing
`<style />` is not a block.
