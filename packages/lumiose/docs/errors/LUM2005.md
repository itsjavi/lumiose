# LUM2005: Children inserted twice

**Severity:** warning · **Category:** reactivity (2xxx)

<!-- end of generated header -->

> `children` is inserted more than once.

**Reported by:** the compiler. A warning.

## What it means

`children` is lazy: each insertion evaluates it, creating a second set of nodes (or moving the
first). Components below are instantiated twice, with separate state.

Spreading the props onto an element without content of its own inserts `children` too
(`<div {...props} />`, [JSX](../concepts/jsx.md)), so it counts as one insertion. A rest that took
`children` out (`{ children, ...rest }`) inserts none.

## Example

```tsx
export function Tabs(props: { children?: JSX.Element }) {
  return (
    <div>
      <nav>{props.children}</nav>
      <main>{props.children}</main>
    </div>
  );
}
```

## How to fix it

Insert `children` once. To render content several times, accept a render function and call it in
each place:

```tsx
export function Tabs(props: { renderTab: () => JSX.Element }) {
  return (
    <div>
      <nav>{props.renderTab()}</nav>
      <main>{props.renderTab()}</main>
    </div>
  );
}
```
