# LUM1001: Syntax error

**Severity:** error · **Category:** file format (1xxx)

<!-- end of generated header -->

> The file is not valid TSX after its `<style>` blocks are masked.

**Reported by:** the compiler (Vite plugin, language server).

## What it means

The compiler could not parse the module. Lumiose masks `<style>` blocks first, so the error is in
the TSX itself: a missing bracket, an unterminated string, a stray `<` in JSX text, or TypeScript
syntax that OXC does not accept.

## Example

```tsx
export function Price() {
  return <p>Total: {total</p>;
}
```

## How to fix it

Fix the syntax at the reported span. The message comes from the parser and names what it
expected. If the error points into a `<style>` block, check that the block is closed (`LUM1004`)
and that `<style` is not part of an expression.
