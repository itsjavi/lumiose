# LUM5003: Duplicate route

**Severity:** error · **Category:** routing and server (5xxx)

<!-- end of generated header -->

> Two route files produce the same URL pattern.

**Reported by:** the route scanner (`lumen check`, typegen, dev server).

## What it means

Each URL pattern must come from one file. Groups add no segment and `index` maps to its folder, so
different paths can collide.

## Example

```
src/routes/blog.stsx
src/routes/blog/index.stsx            both are /blog
src/routes/(shop)/cart.stsx
src/routes/cart.stsx                  both are /cart
```

## How to fix it

Delete or rename one of the files. Param names do not distinguish routes: `[id].stsx` and
`[slug].stsx` in the same folder also collide.
