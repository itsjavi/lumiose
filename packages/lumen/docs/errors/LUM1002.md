# LUM1002: Unsupported by this compiler version

**Severity:** error · **Category:** file format (1xxx)

<!-- end of generated header -->

> The code uses a construct or target that this compiler version does not support yet.

**Reported by:** the compiler.

## What it means

The construct parses, but this version of the Lumen compiler cannot compile it, or the requested
compile target is not available. The message names the construct.

## How to fix it

Rewrite the code with a supported construct (the message suggests one when there is an obvious
alternative), or upgrade `lumen`. If you believe the construct should be supported, report it with
the smallest file that triggers the diagnostic.
