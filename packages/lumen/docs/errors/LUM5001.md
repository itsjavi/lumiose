# LUM5001: Request API used during prerender

**Severity:** error · **Category:** routing and server (5xxx)

<!-- end of generated header -->

> A request API is used while a `static` route is prerendered.

**Reported by:** planned with prerendering (`lumen build`).

## What it means

`static` routes (the default) are rendered at build time, where there is no request: no cookies,
headers, query string or `locals`. Using `request()`, `cookies()`, `locals()`, a form action or
`response()` there cannot work.

## Example

```tsx
export default function Home() {
  const theme = cookies().get("theme");
  return <h1 class={theme}>Home</h1>;
}
```

## How to fix it

Render the route per request: `export const mode = "server";`. Or keep the route static and move
the request-dependent part into an island that reads it in the browser or calls an endpoint.
