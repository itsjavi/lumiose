# LUM3014: CSS syntax error

**Severity:** error · **Category:** styles (3xxx)

<!-- end of generated header -->

> Lightning CSS could not parse a `<style>` block, or could not minify or print it.

**Reported by:** the CSS compiler (`lumen_css`). The Vite plugin surfaces it once the CSS pipeline lands.

## What it means

Blocks are plain CSS, compiled by Lightning CSS. A syntax error it cannot recover from (an
unbalanced brace, an unterminated string, an invalid at-rule prelude) stops the block from
compiling. The message is Lightning CSS's own and points at the CSS.

## Example

```stsx
export function Card() {
  return (
    <div class="card">
      <style>
        .card { padding: 1rem;
      </style>
    </div>
  );
}
```

## How to fix it

Fix the CSS at the reported position. Sass syntax (`$variables` with values, `@mixin`, `@include`)
is not CSS; `$name` only reads JS constants. CSS nesting is supported.
