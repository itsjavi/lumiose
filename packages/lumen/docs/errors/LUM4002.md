# LUM4002: Non-serializable island prop

**Severity:** error · **Category:** islands and boundaries (4xxx)

<!-- end of generated header -->

> An island prop (or SPA route data) is not serializable.

**Reported by:** the server runtime, with the path of the offending value.

## What it means

Island props travel from the server to the browser as data-only JSON. Supported: JSON values plus
`undefined`, `NaN`/`Infinity`, `BigInt`, `Date`, `URL`, `Map` and `Set`. Functions, symbols, class
instances, promises and cycles cannot be serialized. SPA routes get the same rule for their data,
so `request`, `cookies` and `locals` are not passed in.

## Example

```stsx
export default function Page() {
  return <Editor client:load onSave={(text: string) => save(text)} />;
}
```

## How to fix it

Pass data only. Do the work inside the island (it can call an endpoint with `fetchJSON` or post a
form with `submit()`), or convert values to plain objects before passing them.
