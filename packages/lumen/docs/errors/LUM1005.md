# LUM1005: Unknown `<style>` attribute

**Severity:** error · **Category:** file format (1xxx)

<!-- end of generated header -->

> A `<style>` block has an attribute other than `global`.

**Reported by:** the scanner (compiler, `lumen check`, language server).

## What it means

Blocks are plain CSS scoped by placement. The only allowed attribute is `global`, which makes the
block unscoped. `lang`, `media`, `scoped`, `type` and others are not supported: there is no Sass
inside `<style>`, and media queries go inside the CSS.

## Example

```stsx
<style lang="scss">
  .card { .title { color: red; } }
</style>
```

## How to fix it

Remove the attribute. Use `@media` inside the block instead of `media=""`, CSS nesting instead of
Sass, or import a `.scss` file through Vite. For app-wide CSS, write `<style global>`.
