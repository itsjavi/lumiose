# LUM5002: Invalid route file

**Severity:** error · **Category:** routing and server (5xxx)

<!-- end of generated header -->

> A file under `src/routes` is not a valid route file.

**Reported by:** the route scanner (`lumen check`, typegen, dev server).

## What it means

Every file under `src/routes` is a route: pages (`.stsx`, `.tsx`), endpoints (`.ts`), or the special
`_layout`, `_404` and `_error` pages. The message says which rule failed, for example:

- a name starting with `_` other than `_layout`, `_404`, `_error`;
- a special file that is not a page (`_layout.ts`);
- an invalid segment (`[]`, `[a-b]`, a group used as a file name, unsafe characters);
- `export const mode` that is not a string literal of `static`, `server` or `spa`, or `ssr` that is
  not `true`/`false`, or `let` instead of `const`.

## Example

```
src/routes/_helpers.ts       not a route file
src/routes/(admin).stsx      route groups must be folders
```

## How to fix it

Follow the `help` text. Move shared modules out of `src/routes` (to `src/lib` or
`src/components`), make groups folders (`(admin)/index.stsx`), and declare `export const mode =
"server";` with a literal.
