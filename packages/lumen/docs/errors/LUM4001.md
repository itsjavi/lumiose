# LUM4001: Island component is not exported

**Severity:** error · **Category:** islands and boundaries (4xxx)

<!-- end of generated header -->

> A component used as an island (`client:*`) is not exported from its module.

**Reported by:** the compiler.

## What it means

An island's server record names its module and export (`/src/Counter.stsx#Counter`), and the
browser imports that export to hydrate it. A component that is not exported cannot be imported.

## Example

```stsx
function Counter() {
  return <button>0</button>;
}

export default function Page() {
  return <Counter client:load />;
}
```

## How to fix it

Export the component: `export function Counter() { … }`. It may stay in the same file.
