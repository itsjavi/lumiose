# LUM3005: Unused scoped selector

**Severity:** warning · **Category:** styles (3xxx)

<!-- end of generated header -->

> A selector in a scoped `<style>` block matches no element of its scope.

**Reported by:** the CSS compiler (`lumen_css`), in `lumen/vite`, `lumen check` and the language server. A warning.

## What it means

A scoped block only styles the templates of its scope (the file, the component, or for a block
nested under an element, that element's subtree). A selector whose classes, ids or tags never
appear in those templates cannot match anything: usually a typo, leftover CSS, a selector meant
for a child component, or one meant for a sibling subtree. The message names the scope, such as
"matches no element in the `<p>` subtree of component `Tree`".

## Example

```stsx
export function Card() {
  return (
    <div class="card">
      <style>
        .crad { padding: 1rem; }
      </style>
    </div>
  );
}
```

## How to fix it

Fix the selector or delete the rule. To style an element rendered by a child component, pass it a
`class` (class passthrough carries your scope) or use `:deep(.child)`. For classes added from
outside the scope at runtime, use `:global(.name)`.
