# LUM3008: Non-constant `$` reference

**Severity:** error · **Category:** styles (3xxx)

<!-- end of generated header -->

> A `$name` reference in CSS does not resolve to a build-time constant.

**Reported by:** planned (not reported by this version; such references are left unsubstituted).

## What it means

`$name` is inlined into the CSS at build time, so the value must be statically evaluable: a
top-level `const`, a `const` of the enclosing component (component blocks only), or an
`export const` of another module, made of literals, template literals of constants, simple
arithmetic or members of `as const` objects. Signals, `let`s, function results and props are not.

## Example

```stsx
export function Bar(props: { pct: number }) {
  return (
    <div class="bar">
      <style>
        .bar { inline-size: $props.pct; }
      </style>
    </div>
  );
}
```

## How to fix it

Pass runtime values through a custom property:

```stsx
<div class="bar" style={{ "--pct": `${props.pct}%` }}>
  <style>
    .bar { inline-size: var(--pct); }
  </style>
</div>
```
