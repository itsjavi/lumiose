# LUM3012: Custom property set but never read

**Severity:** warning · **Category:** styles (3xxx)

<!-- end of generated header -->

> A custom property is set in a component's `style` prop but no CSS reads it.

**Reported by:** planned (not reported by this version). Another file's CSS may read the property,
so the check has to be project-wide. A warning.

## What it means

Runtime values reach CSS through custom properties: `style={{ "--progress": pct() }}` plus
`var(--progress)` in a block. A property that is set but never read with `var()` in the scope's
CSS does nothing: usually a typo or leftover code.

## Example

```stsx
export function Bar(props: { pct: number }) {
  return (
    <div class="bar" style={{ "--progres": `${props.pct}%` }}>
      <style>
        .bar { inline-size: var(--progress); }
      </style>
    </div>
  );
}
```

## How to fix it

Make the names match, or remove the unused property. Properties consumed by global CSS or other
components are fine to keep; the warning only knows the CSS of the scope.
